# Diccionario de palabras emocionales para el análisis del diario de Lutra (docs/METRICS.md §4.7).
# Diccionario propio, inspirado en las categorías de emoción positiva / negativa de LIWC
# (Pennebaker; adaptación al español de Ramírez-Esparza et al., 2007), sin copiar su contenido.
#
# Formato: una entrada por línea. "palabra" = coincidencia exacta; "raiz*" = cualquier palabra que
# empiece así. Se ignoran mayúsculas y tildes. Las líneas con # son comentarios.
#
# Criterios:
# - Raíces largas para no capturar palabras sin relación ("mal" solo como palabra exacta, no "mal*",
#   que incluiría "maleta").
# - Se excluyen palabras muy ambiguas: "solo" (casi siempre "solamente"), "quiero" (deseo, no
#   afecto), "nostalgia" (valencia mixta), "animo" (neutro: "estado de ánimo").
# - No se detectan negaciones ("no estoy triste" cuenta como negativa): limitación documentada.
